# Packages tvtune.sh turns off on the TV (TCL 50S450G, Google TV, Android 11).
#
#   x  = turn off when you run the "apply" step
#   -  = leave on (change the - to x if you don't use that feature)
#
# "Off" means `pm disable-user`: nothing is deleted, and the "restore" step turns
# back on everything the script turned off. Packages that aren't on your TV are
# skipped, so it's fine that this list covers more than one TCL firmware.
#
# Never add these. Community reports tie them to boot loops, lost HDMI/antenna
# inputs, a dead remote, or a broken Wi-Fi setup:
#   com.tcl.tv  com.tcl.tvinput  com.tcl.dashboard  com.tcl.systemserver
#   com.tcl.system.server  com.tcl.suspension  com.tcl.autopair
#   com.tcl.tcl_bt_rcu_service  com.tcl.initsetup  com.tcl.providers.config
#   com.tcl.framework.custom  com.tcl.micmanager  com.tcl.factory.view
#   com.tcl.waterfall.overseas  com.android.location.fused
#   com.google.android.gms  com.android.vending  com.google.android.katniss
#   com.google.android.tv.remote.service
